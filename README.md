# 2Nouta

проект по ооп

Два ноутбука общаются по TCP-сокетам. На клиенте (Ноутбук 2) есть кнопка Start/Stop. При нажатии клиент отправляет команду серверу (Ноутбук 1), и окно сервера меняется: по `START` рисуется квадрат, по `STOP` показывается текст. Окна сделаны на Tkinter, используется только стандартная библиотека Python.

Программа собирается в один файл `2Nouta.exe` для Windows. Один и тот же exe запускается и как сервер, и как клиент.

## Файлы

- `main.py` — точка входа: спрашивает в консоли режим (`1` — Сервер, `2` — Клиент) и запускает нужное окно
- `server.py` — класс `ServerApp`: окно с Canvas и TCP-сервер, запускается на Ноутбуке 1
- `client.py` — класс `ClientApp`: окно с кнопкой Start/Stop, запускается на Ноутбуке 2
- `discovery.py` — автопоиск сервера в сети: ответчик на `DISCOVER` для сервера и сканер подсети для клиента
- `config.py` — порты, размер буфера, названия команд и настройки поиска
- `build.ps1` — сборка `dist\2Nouta.exe`

## Сборка

Нужен Python 3 с https://www.python.org/downloads/ (с ним ставятся Tkinter и лаунчер `py`). Python из MSYS2/Cygwin не подойдёт. В PowerShell в папке проекта:

```
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

Скрипт создаст `.venv`, поставит в неё PyInstaller и соберёт `dist\2Nouta.exe`. Файл автономный: Python и библиотеки упакованы внутрь, его можно просто скопировать на другой компьютер с Windows 10/11 (64-бит) и запустить.

Exe не подписан, поэтому при первом запуске Windows SmartScreen может показать «Windows защитила ваш компьютер»: нажмите «Подробнее» → «Выполнить в любом случае».

## Запуск

Запустите `2Nouta.exe` (двойным кликом или из консоли). Откроется консоль с вопросом:

```
1 - Сервер
2 - Клиент
Выберите режим:
```

Введите `1` или `2` и нажмите Enter. На другой ввод программа спросит ещё раз. После выбора откроется окно сервера или клиента. Когда окно закрыто или произошла ошибка, консоль пишет, что случилось, и ждёт нажатия любой клавиши.

Режим можно передать аргументом, тогда вопроса не будет: `2Nouta.exe server`, `2Nouta.exe client` или `2Nouta.exe client 192.168.0.193`.

### В двух окнах на одном компьютере

1. Запустите `2Nouta.exe` и выберите `1` (Сервер).
2. Запустите тот же `2Nouta.exe` ещё раз и выберите `2` (Клиент).

Клиент сам найдёт сервер на этом же компьютере. Два экземпляра друг другу не мешают: каждый распаковывается в свою временную папку, а файл `last_ip.txt` рядом с exe пишет только клиент. Сервер на одном компьютере может быть только один.

### На двух компьютерах

1. Подключите оба компьютера к одной сети Wi-Fi.
2. Скопируйте `2Nouta.exe` на оба компьютера.
3. На Ноутбуке 1 запустите exe и выберите `1`.
4. На Ноутбуке 2 запустите exe и выберите `2`.

**Брандмауэр Windows.** Сервер принимает входящие подключения на TCP-портах `55555` (команды) и `55556` (поиск). При первом запуске сервера Windows покажет окно брандмауэра: разрешите доступ и отметьте «Частные сети». Если окно закрыли или нажали «Отмена», клиент сервер не найдёт. Тогда добавьте правило вручную (PowerShell от имени администратора, путь замените на свой):

```
New-NetFirewallRule -DisplayName "2Nouta" -Direction Inbound -Program "C:\путь\к\2Nouta.exe" -Action Allow -Profile Private
```

Сеть Wi-Fi в Windows должна быть отмечена как «Частная»: для «Общедоступной» сети входящие подключения обычно закрыты.

IP вводить не нужно, клиент ищет сервер сам:

1. Сначала проверяет последний найденный адрес из `last_ip.txt`.
2. Если там никто не ответил, определяет свой IP и маску подсети и параллельно опрашивает все адреса подсети на порту `55556` (таймаут 300 мс на адрес). Каждому адресу отправляется `DISCOVER`, сервер отвечает `HERE <имя компьютера>`.
3. Если ответило несколько серверов, выбирается тот, что ответил быстрее всех.
4. Клиент подключается к найденному серверу на порт `55555` и сохраняет его IP.

Если сервер не найден, в окне клиента появится сообщение. IP можно ввести вручную в поле «IP сервера» или нажать «Найти в сети» ещё раз. IP можно передать и аргументом, тогда поиск не выполняется:

```
2Nouta.exe client 192.168.0.193
```

IP сервера можно узнать на Ноутбуке 1 командой `ipconfig` (строка «IPv4-адрес»). Проверка связи с Ноутбука 2:

```
ping 192.168.0.193
Test-NetConnection 192.168.0.193 -Port 55556
```

- ping не проходит — ноутбуки в разных сетях или включена изоляция клиентов;
- ping проходит, но `TcpTestSucceeded : False` — брандмауэр на Ноутбуке 1 блокирует `2Nouta.exe`;
- включён VPN — клиент может искать сервер не в той подсети; отключите VPN или введите IP вручную.

Если соединение пропало, нажмите в окне клиента «Переподключиться». Сервер после отключения клиента сам снова ждёт подключения.

## Запуск из исходников

Без сборки, если установлен Python с Tkinter: `python main.py` (или `python main.py server`, `python main.py client 192.168.0.193`).

## Как работает

1. Сервер открывает окно сразу и ждёт клиента на порту `55555` в отдельном потоке. В окне виден статус: «Ожидание клиента...», «Клиент подключён», «Соединение потеряно».
2. Клиент подключается к серверу. Состояние Start/Stop хранится на клиенте.
3. При нажатии кнопки клиент отправляет команду и меняет надпись на кнопке:
   - `START` — сервер рисует квадрат;
   - `STOP` — сервер показывает текст.
4. Каждая команда заканчивается символом `\n`. TCP передаёт поток байтов, поэтому несколько команд могут прийти одним куском или одна команда двумя. Сервер складывает данные в буфер и разбирает их по `\n`.
5. Окно Tkinter обновляется только из главного потока: сетевой поток передаёт изменения через `root.after(0, ...)`.
6. Поиск работает на отдельном порту `55556`, чтобы проверочные подключения не мешали каналу команд на `55555`.
7. При закрытии окна сокеты закрываются.
