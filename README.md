# 2Nouta

проект по ооп

Два ноутбука общаются по TCP-сокетам. На клиенте (Ноутбук 2) есть кнопка Start/Stop. При нажатии клиент отправляет команду серверу (Ноутбук 1), и окно сервера меняется: по `START` рисуется квадрат, по `STOP` показывается текст. Окна сделаны на Tkinter, используется только стандартная библиотека Python.

## Файлы

- `server.py` — класс `ServerApp`: окно с Canvas и TCP-сервер, запускается на Ноутбуке 1
- `client.py` — класс `ClientApp`: окно с кнопкой Start/Stop, запускается на Ноутбуке 2
- `config.py` — IP сервера, порт, размер буфера и названия команд

## Что нужно

Только Python 3. Устанавливать ничего не нужно.

## Проверка на одном ноутбуке

Откройте два терминала в папке проекта. В первом:

```
python server.py
```

Во втором:

```
python client.py
```

По умолчанию в `config.py` указан `SERVER_IP = "127.0.0.1"`, то есть клиент подключается к этому же компьютеру.

## Запуск на двух ноутбуках

1. Подключите оба ноутбука к одной сети (надёжнее всего — раздача с телефона).
2. На Ноутбуке 1 запустите сервер и разрешите доступ в окне брандмауэра:

```
python server.py
```

3. Узнайте IP Ноутбука 1:
   - Windows: `ipconfig`, строка «IPv4-адрес»;
   - Linux: `ip a`, строка `inet` у сетевого интерфейса (например, `wlan0`).
4. На Ноутбуке 2 впишите этот IP в `config.py`:

```python
SERVER_IP = "192.168.0.193"
```

5. Запустите клиент на Ноутбуке 2:

```
python client.py
```

IP можно не менять в `config.py`, а передать аргументом:

```
python client.py 192.168.0.193
```

На Ноутбук 2 нужно скопировать `client.py` и `config.py`.

Запускайте через терминал: кнопка Run в VS Code не передаёт IP.

## Если не подключается

Проверьте с Ноутбука 2, видна ли сеть и открыт ли порт:

```
ping 192.168.0.193
Test-NetConnection 192.168.0.193 -Port 55555
```

- ping не проходит — ноутбуки в разных сетях;
- ping проходит, но `TcpTestSucceeded : False` — брандмауэр на Ноутбуке 1 блокирует Python;
- в окне клиента «Не удалось подключиться к серверу» — сервер не запущен или указан неверный IP.

Если соединение пропало, нажмите в окне клиента «Переподключиться». Сервер после отключения клиента сам снова ждёт подключения.

## Как работает

1. Сервер открывает окно сразу и ждёт клиента на порту `55555` в отдельном потоке. В окне виден статус: «Ожидание клиента...», «Клиент подключён», «Соединение потеряно».
2. Клиент подключается к серверу. Состояние Start/Stop хранится на клиенте.
3. При нажатии кнопки клиент отправляет команду и меняет надпись на кнопке:
   - `START` — сервер рисует квадрат;
   - `STOP` — сервер показывает текст.
4. Каждая команда заканчивается символом `\n`. TCP передаёт поток байтов, поэтому несколько команд могут прийти одним куском или одна команда двумя. Сервер складывает данные в буфер и разбирает их по `\n`.
5. Окно Tkinter обновляется только из главного потока: сетевой поток передаёт изменения через `root.after(0, ...)`.
6. При закрытии окна сокеты закрываются.
